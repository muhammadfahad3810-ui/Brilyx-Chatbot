Brilyx.com (local embedding demo)

This page stands in for the real www.brilyx.com marketing site during local development. It intentionally styles every button, input, textarea, and div on the page with ugly, aggressive rules so that if the chat widget in the bottom-right corner still renders cleanly, we know its Shadow DOM boundary is doing its job.

Backend must be running at the URL below (see docs/frontend-widget.md for how to start it) and its CORS_ALLOWED_ORIGINS must include the origin this page is served from.

Edit the data-api-base-url attribute on the <script> tag at the bottom of this file to point at your backend if it isn't on the default http://127.0.0.1:8000.
